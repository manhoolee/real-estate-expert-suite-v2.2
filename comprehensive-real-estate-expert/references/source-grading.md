# 来源与主张分级

## 来源等级

| 等级 | 来源 | 常见用途 |
|---|---|---|
| A | 法定规划、政府公告、土地出让/成交文件、登记或正式内部系统 | 范围、指标、成交、监管事实 |
| B | 企业正式披露、权威研究机构、经核验的项目台账 | 经营、市场与竞品判断 |
| C | 主流媒体、平台数据库、微信公众号、销售口径 | 线索、补充背景、待核验观点 |
| D | 传闻、匿名截图、无日期转述、生成式内容 | 不进入事实层，只作调查线索 |

`FACT-A/B/C` 表示事实采用的最高来源等级，不代表事实永远正确；仍需检查日期、范围和口径。

## 主张账本字段

`claim_id, claim_text, claim_type, scope_id, source_ids, as_of_date, confidence, status, contradiction, notes`

`claim_type` 使用 `FACT / DERIVED / INFERENCE / HYPOTHESIS / RECOMMENDATION`。`status` 使用 `verified / provisional / disputed / superseded`。

## 冲突处理

1. 先检查是否因范围、日期、单位或统计定义不同；
2. 若可兼容，分别标明口径，不强行合并；
3. 若互斥，优先原始、法定、更新且更贴近目标范围的来源；
4. 未能消解时并列展示并降低结论置信度；
5. 保留被替代来源及原因，禁止静默覆盖。

## 引用最小格式

`[来源ID｜等级｜发布/数据日期｜目标范围｜链接或文件路径]`

派生数字另列公式，例如：`住宅计容 = AT111333 110,000 + AT111337 112,740 = 222,740㎡`。
