# 项目研究参考报告

本目录收录本套件生成并完成交付质检的两份项目研究报告，用于展示研究、产策、复盘、正式文案、视觉交付和证据边界的综合应用。

## 广州天河马场地块一期

报告聚焦项目范围、法定规划、市场环境、竞品与客群、产品定位、价格货值、推售节奏和主要决策条件。报告同时保留公开资料清单，便于对关键判断进行回查。

## 广州保利南方面粉厂项目

报告聚焦项目阶段复盘、规划兑现、产品与销售表现、市场竞争、风险信号和下一步经营动作。报告同时保留截至研究日的公开资料清单，区分已确认事实、分析判断和仍需补充的项目数据。

## 文件说明

每个项目目录包含：

- Markdown 正文，适合检索、复用和版本管理；
- HTML 正式成品，适合离线打开和阅读；
- 公开资料清单，记录研究日期、来源和数据边界。

报告中的规划、市场、销售和工程信息具有明确的研究时点与适用范围。对外使用时，应结合最新官方文件、项目正式披露和实际经营数据进行复核。
