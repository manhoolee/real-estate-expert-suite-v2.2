## 一、工作成果

v2.2 已形成一套完整的地产研究与交付 skill 套件，覆盖：

- 综合研判总控；
- 城市、规划、土地、市场、竞品和客群研究；
- 产品定位、户型、价格、货值和推售策略；
- 品牌故事、营销、销售话术和社群运营；
- 微信资料归档；
- 正式报告文案编辑；
- 报告视觉设计与多端交付；
- 交付质量验收；
- 小红书、抖音、朋友圈、公众号等社交内容适配。

本版本已经把以下原则固化到核心 skill：

1. 所有面向用户成果必须达到严肃、准确、可直接提交的正式内容标准；
2. 禁止用户与 agent 对话、提示、备注、工作流、制作说明、内部推理和质检记录进入最终成品；
3. 来源、假设、核验状态和计算底稿独立管理，不污染正文；
4. 图片和页面不得出现文字重叠、遮挡、溢出、重复渲染或导出裁切；
5. 交付质检作为正式提交、发布和决策的 P0/P1 放行门槛。
