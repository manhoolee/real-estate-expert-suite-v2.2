# HOOSLAND 综合地产研判策划专家套件 v2.2

[![License: MIT](https://img.shields.io/badge/Code%20%26%20Skills-MIT-blue.svg)](LICENSE)
[![Content: CC BY 4.0](https://img.shields.io/badge/Content-CC%20BY%204.0-lightgrey.svg)](LICENSE-CONTENT.md)

本套件包含 1 个总控、5 个专业模块和 4 个最终交付模块：

- `comprehensive-real-estate-expert`：跨模块路由、项目状态、证据与质量闸门；
- `real-estate-research`：城市、规划、土地、市场、竞品与客群研究；
- `real-estate-product-strategy`：产品、户配、价格、货值与推售策略；
- `real-estate-storyline-marketing`：品牌故事、营销、内容与销售话术；
- `real-estate-community-operations`：社群、私域、老带新与长期客户价值；
- `wechat-article-exporter`：微信文章转换与研究资料归档入口。
- `real-estate-report-editorial`：管理层报告文案编辑与结论整理；
- `real-estate-report-design`：报告版式、图表、图片与多端视觉交付；
- `real-estate-delivery-qa`：发布前内容、数据、文件和视觉质检。
- `real-estate-social-promotion`：将研究和产策报告拆解成小红书、公众号、视频号、抖音、微博、LinkedIn等平台的宣传内容包，并在明确授权后衔接发布。

## v2.2 重点

范围身份、来源/主张账本、L0–L2 计算许可、冲突处理、项目状态、确定性产品测算、范围检查、报告文案、报告设计、交付质检、社交内容拆解、平台化改写、宣传素材和多端发布前检查。

参考项目报告见：[项目研究参考报告](references/project-reports/README.md)。
